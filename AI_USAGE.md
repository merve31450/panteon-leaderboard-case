# AI Usage

ChatGPT and Codex were used as development assistants during this project.

AI assistance was used for:

- Project planning and implementation guidance
- Debugging TypeScript and Express issues
- Designing the Redis Sorted Set leaderboard flow
- Generating the initial React dashboard structure
- Improving project documentation

All generated code was reviewed, manually tested, and adjusted by the developer before being included in the project. The developer remained responsible for implementation decisions, validation, and final project quality.
