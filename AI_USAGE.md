# AI Usage

ChatGPT and OpenAI Codex were used as development assistants during this project.

AI assistance helped with:

- planning the full-stack implementation
- debugging TypeScript, Express, React, and deployment issues
- designing the Redis Sorted Set leaderboard approach
- reasoning about scalable leaderboard behavior for 10M+ registered players and 2M DAU
- improving frontend behavior and fixing UI integration issues
- preparing deployment guidance for Render, Vercel, and Redis
- writing and revising project documentation

All AI-assisted code and documentation were reviewed by the developer. The code was manually tested, adjusted, and accepted by the developer, who remained responsible for final implementation decisions and project quality.
