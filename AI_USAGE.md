# AI Usage

AI tools were used as development assistants during this project, but they did
not replace engineering decisions or final validation.

ChatGPT was used for:

- requirement analysis
- architecture discussion
- debugging support
- test planning
- reviewing case coverage

Codex / VS Code AI assistant was used for:

- implementation support
- refactoring assistance
- documentation updates
- boilerplate generation

The project was not blindly generated by AI. Key design and implementation
areas were manually reviewed and validated, including Redis leaderboard usage,
PostgreSQL, MongoDB, the stateless backend design, the admin guard, the large
seed demo, and the React component structure.

Final validation was completed with npm builds, curl tests, Docker,
PostgreSQL, MongoDB, Render, and Vercel. The developer remained responsible for
the final implementation decisions, manual review, testing, and project
quality.
